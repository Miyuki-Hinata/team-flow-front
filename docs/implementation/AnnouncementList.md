# AnnouncementList（リファクタ）

## 何を作ったか
`src/components/AnnouncementList.tsx` のリファクタ。お知らせカードを並べるだけのリスト。素の器 `<div>` を、theme トークンで縦積み＋カード間の間隔を付けた styled コンテナに置き換えた。

## 何を何に置き換えたか
| 旧（素の実装） | 新 | 補足 |
|---|---|---|
| `<div>`（スタイル無し・カードが密着） | `List`（styled.div、縦積み＋gap） | カード間に間隔を付与 |

このコンポーネントには素の `<button>/<input>/<select>/<span>` は無く、置換対象はカードを包む器の `<div>` のみだった。中身のカードは既にリファクタ済みの `AnnouncementCard` に委ねている。

## なぜこの設計にしたか
- **リストは「並べ方」だけに責任を絞る**：各カードの見た目は `AnnouncementCard`、そのさらに内側は Card / Badge が持つ。List は「縦に積んで間隔を空ける」というレイアウトだけを担当する（単一責任）。
- **gap をトークンで付けた**：デザイン（`TeamFlow.dc.html` 448行目）ではカード列が `display:flex; flex-direction:column; gap:12px`。旧実装は gap 無しでカードが密着していた。デザインの 12px は spacing トークンに存在しない値のため、§2「定義外の値を追加しない（トークンのみ使う）」に従い、最も近い標準余白 `spacing.md`（16px）を採用し、12px の直書きは避けた。

## 挙動を維持するために気をつけた点
- **props インターフェースは不変**（`announcements` / `onRead`）。親からの呼び出しはそのまま。
- **map のロジック・key・onRead の受け渡しは変更なし**。見た目（器）だけを置換。
- **default export のまま**：親が default import で読み込んでいるため維持。

## 使用した theme トークン
- 余白：`spacing.md`（カード間の gap）

## 判断した点・申し送り
- **gap は 12px → spacing.md(16px) に丸めた**：トークン厳守のためのトレードオフ。厳密なデザイン一致（12px）が必要なら、theme に 12px の余白トークン（例：`spacing.smd`）を追加する案もあるが、トークン体系（8の倍数基準）を崩すため今回は見送り、既存トークンで最も近い値を採用した。

## 面接で説明できるポイント
- **レイアウトと中身の責任分離**：List＝並べ方、Card＝1件の見た目、という層構造。
- **トークン厳守と実値のギャップの扱い**：デザインの 12px がトークンに無いとき、直書きせず最も近いトークンに寄せる判断（一貫性 > ピクセル厳密さ）を説明できる。
