# TaskList（リファクタ）

## 何を作ったか
`src/components/TaskList.tsx` のリファクタ。タスクカードを並べるだけのリスト。素の器 `<div>` を、theme トークンで縦積み＋カード間の間隔を付けた styled コンテナに置き換えた。お知らせ系の AnnouncementList と同一方針。

## 何を何に置き換えたか
| 旧（素の実装） | 新 | 補足 |
|---|---|---|
| `<div>`（スタイル無し・カードが密着） | `List`（styled.div、縦積み＋gap） | カード間に `spacing.md` の間隔 |

素の `<button>/<input>/<select>/<span>` は無く、置換対象は器の `<div>` のみ。カードの見た目はリファクタ済み `TaskCard` に委譲。

## なぜこの設計にしたか
- **リストは「並べ方」だけに責任を絞る**：各カードの見た目は `TaskCard`、その内側は Card / Badge が持つ。List は縦に積んで間隔を空けるレイアウトのみ担当（単一責任）。
- **gap は AnnouncementList と同じ `spacing.md`(16px)**：お知らせ系と揃えることで、一覧画面ごとにカード間隔がバラつかず一体感が出る。旧実装は gap 無しでカードが密着していた。

## 挙動を維持するために気をつけた点
- **props インターフェースは不変**（`tasks`）。
- **map のロジック・key の受け渡しは変更なし**。見た目（器）だけを置換。
- **default export のまま**維持。

## 使用した theme トークン
- 余白：`spacing.md`（カード間の gap）

## 面接で説明できるポイント
- **一覧レイアウトの統一**：お知らせ／タスクで同じ間隔トークンを使い、画面をまたいだ一体感を担保している。
- **責任分離**：List＝並べ方、Card＝1件の見た目、という層構造。
