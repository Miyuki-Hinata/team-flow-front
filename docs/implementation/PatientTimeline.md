# PatientTimeline

## 何を作ったか
受け持ち患者のタスクを時系列で見せる表示専用コンポーネント（**レール型タイムライン**）。左に時刻＋縦レール＋ドット、右にタスクカードを並べ、午前/午後/夜で区切る。期限超過は上部に独立セクション（赤）。`MyPatientsPage` に統合済み。

同じ縦レール上に2種類の目盛りを時刻順で混在させる：**タスクが無い時間は1時間おきの薄いグレー目盛り(HH:00)**（空き時間がひと目で分かる）、**タスクのある時刻はその実時刻(HH:mm)＋優先度ドット＋カード**。同時刻に2件以上あるときは、沈んだ面の**囲み（GroupBox「同時刻 N件」）**でまとめ、白いカードが浮いて「同時刻のまとまり」と分かるようにする。正確な時刻はカードにも表示。

## 設計の変遷（なぜ比例グリッドをやめたか）
初版は「0:00〜24:00 の比例配置グリッド＋列分割」だったが、実機で以下の問題が出た：
- **同時刻が潰れる**：絶対配置で完全に重なり1つしか見えない。列分割しても同時刻が増えるほど1列が細くなる。
- **狭い端末で読めない**：横分割はモバイルで破綻。
- **時刻がズレて見える**：位置で時刻を読ませるため、チップ高さのぶん誤差が出る。
- 24hグリッドは空白が多く間延び。

→ これらは方式の限界と判断し、**アクティビティタイムライン（レール型）**へ作り替えた。

## なぜこの設計にしたか
- **時刻を明示ラベルで置く**（位置で読ませない）→ ズレ感が消える。
- **同時刻は同じ時刻の下にカードを縦積み**（`TimeGroup`）→ 何件でも潰れない・ホバー不要・モバイル可。
- **午前(0-11)/午後(12-17)/夜(18-)で区切る**（`buildPeriods`）→ “1日の流れ”が出る。空の時間帯は出さない。時間帯→同時刻の2段グルーピングは `Map` で時刻順を維持する。
- **優先度はレールのドット色のみ**（高=赤/中=黄/低=緑、`PriorityBadge` の tone と統一）。同時刻グループのドットは**最も緊急な優先度**で塗る。カード内に優先度ピルは出さず、情報量を絞る。
- **リンクの下線を廃止**：カード全体＝タスク詳細（ホバーで反応）、患者名は**ティールのピル**＝患者詳細。全体のカードUIと質感を統一。入れ子アンカーの不正HTMLを避け、`role="link"`＋`tabIndex`＋`onKeyDown` で構成、患者名は `stopPropagation` で親のタスク遷移を止める。
- **期限超過は時間軸に載せず上部へ独立**（見落とし防止・赤で強調＝メリハリ）。
- **表示専用（state を持たない）**：取得・絞り込みは呼び出し側の責任（`PatientCard` と同じ分担）。ナビゲーションのみ `useNavigate` を使う。

## どのお手本に倣ったか
`PatientCard`（表示に責任を絞る／theme トークン／単一責任）、`Card`（白背景＋枠＋角丸のカード質感）、空表示は `EmptyState`。

## 使用した theme トークン
- `spacing.*`、`radius.lg`/`radius.full`、`fontSize.*`、`fontWeight.bold`
- `colors.semantic.danger`（期限超過）/ `warning` / `success`（優先度ドット）
- `colors.surface.raised`/`sunken`、`colors.border.default`/`strong`、`colors.text.*`
- `colors.brand.teal`/`tealDark`（患者ピル）
- 実寸 px（ドット12px・レール幅14px・時刻列46px）はレイアウト定数として直書き（既存方針）

## 統合（MyPatientsPage）
受け持ちが変わるたび、`assignedPatients` を依存にした `useEffect` で各患者の `getTasksByPatientId` を **`Promise.all` 並列取得** → `flat()` で1本化して渡す。一覧/タイムラインは `Tabs` で切替。
