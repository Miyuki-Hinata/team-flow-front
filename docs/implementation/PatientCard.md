# PatientCard（見た目改善）

## 何を作ったか
`src/components/ui/PatientCard.tsx` の見た目をデザイン（`TeamFlow.dc.html` の患者カード / README §3）に寄せた。素の縦積みから **横並び行レイアウト**（アイコン | 本文 | 右シェブロン）に変更。既存の props・テスト・依存コンポーネント（Card / PatientIcon）はそのまま維持。

## 変更内容
| 旧 | 新 | 補足 |
|---|---|---|
| PatientIcon と `<div>`×3 が Card 直下（暗黙的な縦積み） | `Row`（横並び・`width:100%`）+ `Content`（本文の縦積み・`align-items:flex-start`）+ `Chevron` | デザインの行レイアウトに準拠。氏名の左寄せを明示 |
| 素の `<div>` 3行（氏名 / 振り仮名 / メタ1行） | `Name`（18px/bold）+ `Kana`（xs/muted）+ `Meta`（wrap 折り返し） | それぞれ theme トークンで整理 |
| メタ「{age}歳　{部署}　担当医師 {名}」（全角空白区切り） | Meta「{age}歳 {性別}・{年齢層} ｜ {部署} ｜ 担当医師 {名}」（Divider `｜` 区切り・3グループ） | 情報を1グループから3グループに増やし、視覚区切りも導入 |
| （なし） | **右端シェブロン**（`>` SVG・muted 色） | クリックで詳細に飛ぶ導線を暗示 |
| （なし） | **性別・年齢層の日本語表示**（男性・女性・不明 × 小児・成人・高齢） | Patient 型のデータ（`sex` / 年齢から算出）を活用 |

## なぜこの設計にしたか
### 横並び行レイアウト
デザインの患者カードは **アイコン | 本文 | 右エリア**の横並び行。現状の縦積みだと情報密度が低く、一覧としての視認性も悪い。`Row`（flex）+ `Content`（本文の縦積み）+ `Chevron` の3ブロック構成にし、`Content` に `flex: 1 1 auto; min-width: 0` を付けて残り幅を占めさせつつ、長い名前でもはみ出さないようにした（フレックス子要素の定石）。

### 氏名の左寄せを明示（実機で「中央寄り」に見えた問題への対策）
実機確認で氏名が Meta より右寄りに見えていたが、原因は**メタ情報が短くて（1グループのみ）Content の子要素の左端が同じでも視覚的に錯覚が起きていた**こと。対策として：
1. `Row` に `width: 100%` を明示（親幅を確実に占める）
2. `Content` に `align-items: flex-start` を明示（既定 stretch から左寄せ固定へ）
3. **メタ情報を3グループに充実**（年齢＋性別・年齢層 ｜ 部署 ｜ 担当医師）— 横に広がることで氏名の左端との位置関係が視覚的に自然になる

### 区切りは `<Divider>` の独立要素にした
「｜」を疑似要素（`::before`）で足すと `flex-wrap` 時の折り返し計算が狂いやすい（区切り記号が行頭に来る等）。独立した `<span>` にすることで、折り返し時に前後どちらでも自然に流れる。`aria-hidden="true"` を付けてスクリーンリーダーで読み上げされないようにした。

### 表示できる項目のみ入れた（Patient 型に依存）
デザインでは「病室」「状態バッジ」「次の対応」も表示されるが、`Patient` 型（`types/patient.ts`）にこれらのフィールドが**現状無い**。ドメイン拡張が必要な項目は今回入れず、既存フィールドで表現できる**氏名・振り仮名・年齢・部署・担当医**に絞った（＋アイコンで性別×年齢層）。

### 右端シェブロン
Patient 型に依存しない装飾。**クリック導線を示す UI ヒント**として追加。`stroke="currentColor"` で親色を継承する Sidebar/AppHeader と同じインライン SVG パターン。

### Card 本体は変更しない
`ui/Card` は他ページでも使う汎用コンポーネント。PatientCard 側の変更で完結させるため、Card には手を入れず、内側のレイアウトだけを差し替えた（同じ Card を使いつつカードごとに違う中身、という設計を崩さない）。

## 挙動を維持するために気をつけた点
- **氏名の表示は「姓 名」（半角スペース）を維持**：`PatientCard.test.tsx` が `getByText('佐藤 花子')` で完全一致を期待するため、`{patient.lastName} {patient.firstName}` の書き方を守る。
- **年齢・担当医の表示ロジックは不変**：`calcAge` / `getAgeGroup` の呼び出し順、担当医名の `null` → '-' フォールバックはそのまま。
- **props インターフェース不変**（`patient` のみ）。
- **useTheme（性別 → 色ペアの引き当て）**はそのまま。
- 名前付き export（`export const PatientCard`）維持。

## 使用した theme トークン
- 余白：`spacing.md`（Row の gap・Meta の gap）/ `spacing.xs`（Content 縦積みの gap）
- 色：`text.primary`（氏名）/ `text.secondary`（メタ）/ `text.muted`（振り仮名・シェブロン）/ `border.default`（Divider）
- 文字：`fontSize.lg` + `fontWeight.bold`（氏名）/ `fontSize.sm`（メタ）/ `fontSize.xs`（振り仮名）

## 判断した点・申し送り
- **病室・状態バッジ・「次の対応」・赤ストリップ は入れない**：ユーザー指示および Patient 型に該当フィールドが無いため。特に「次の対応」は**実務的にも Task 型と重複する設計になるため、実装するなら Task から導出する方が筋が良い**という判断。将来 Row の右エリアに拡張できる構造にはしてある（Chevron の左に別ブロックを差し込む形）。
- **PatientCard は「表示のみ」のお手本を守った**：クリック導線（`<Link>`）は PatientList 側の責任のまま。カード内では触らない。
